# ouom

**observable universe on mac** — 为工作与学习而生的 macOS 原生浏览器。

- 产品介绍：<https://apple-pc.github.io/ouom/>
- 下载页面：<https://apple-pc.github.io/ouom/download/>

## 项目简介

ouom 使用原生 Swift（SwiftUI + AppKit + WebKit）构建，自研浏览器外壳、导航、桥接与插件宿主架构，渲染由系统 WebKit 承担。应用内置 AI 助手、轻量办公套件、面向学生的学习工作台与新标签页门户；默认完全离线可用，无需注册或登录。

## 本仓库用途

本仓库用于发布 ouom 的产品介绍网站（GitHub Pages）与 macOS 安装包分发：

```
index.html                 产品介绍页
download/index.html        下载子页面
download/ouom-0.1.0.zip    0.1.0 安装包
```

下载页提供 SHA-256 校验值，请在安装前核对。

## 数据存放与可靠性

应用的用户数据只保存在本机 `~/Library/Application Support/ouom/`，不上传、不依赖账号。目录权限 `0700`、数据文件权限 `0600`；每次写入采用原子替换并保留上一份良好副本，文件损坏时自动恢复，无法恢复时隔离留证而不删除。API Key 与访问令牌只存系统钥匙串，界面不回显明文。设置中心可直接查看文件清单、用途、占用、备份数量与最近写入结果。

当前阶段按设计仅实施基础隐私保护：**尚未启用数据加密**，也不提供密码自动填充、站点权限持久化与跨设备同步。

## 能力边界

默认本地 AI 后端是设备端统计式 / 检索式共享小模型，提供抽取式摘要、意图分类、BM25 检索问答与写作变换，**不是大语言模型、不具备生成式回答能力**。云端后端需用户自行配置凭据；办公套件为轻量自研编辑器，PDF 为文本层查看器；CloudKit 同步、插件独立沙箱与 GGUF 微调模型均未启用。
